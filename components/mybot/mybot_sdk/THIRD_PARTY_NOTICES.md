## LVGL pixel-glasses view and retained assets

`platforms/bk7259/display/lvgl_view.cc` renders the pixel-glasses appearance
using fixed LVGL widgets, sampled curves, five small A8 geometry masks, and
four terminal rows. The 23 expression configurations, colors, and motion are
defined in `platforms/bk7259/display/pixel_expression_shapes.h`; the mask
geometry is defined in `platforms/bk7259/display/generate-expression-masks.py`.
Expression mappings, mask reproduction, and resource limits are recorded in
`platforms/bk7259/display/SOURCES.md`.

The preceding status view and generated resources were adapted from
[agora-esp32-devkit commit `19af3bdfaf1dd35461af48def8f9558e3503e755`](https://github.com/AgoraIO-Community/agora-esp32-devkit/tree/19af3bdfaf1dd35461af48def8f9558e3503e755).
Source-font and emoji notices remain preserved after the face rewrite.
The following asset paths are relative to `platforms/bk7259/`.

- `display/pixel_expression_masks.h` contains five immutable A8 geometry masks
  (13631 pixel bytes) generated by the target-owned MIT-licensed
  `display/generate-expression-masks.py`. Its MIT notice and copyright are
  preserved. Generation uses Pillow 10.2.0, fourfold coverage sampling, and
  Lanczos downsampling of geometric contours; no full-face images are imported.
- The view is MIT-licensed. Its terms and current Project Contributors
  copyright notice are in `display/assets/licenses/LVGL_VIEW_LICENSE.txt`;
  the asset API header retains Apache-2.0.
- `display/lvgl_fonts.c` contains the MyBot UI Sans 20-pixel subset derived
  from Source Han Sans SC Normal, copyright 2014-2021 Adobe. It is licensed
  under SIL OFL-1.1 in `display/assets/licenses/LVGL_VIEW_FONT_LICENSE.txt`.
  The target regenerates its 152-glyph subset with
  `display/generate-lvgl-font.py`, adapted from the MIT-licensed
  [agora-esp32-devkit generator](https://github.com/AgoraIO-Community/agora-esp32-devkit/blob/19af3bdfaf1dd35461af48def8f9558e3503e755/scripts/generate-lvgl-font.py),
  to cover the current fixed UI and factory-reset vocabulary.
  The source font revision remains pinned by SHA256
  `1ee89e1669362dee13851129c0a8a791a87521eb4148e5efbf5d26596738e25b`.
  The modified font uses the distinct MyBot UI Sans name.
- `display/pixel_fonts.c` contains renamed BK7259 Terminal 15 and 16 bitmap
  subsets derived from DejaVu Sans Mono Bold. Copyright (c) 2003 Bitstream,
  Inc.; DejaVu changes are in the public domain. The full Bitstream Vera
  license and notices are preserved in
  `display/assets/licenses/TERMINAL_FONT_LICENSE.txt`. The 15-pixel subset
  contains 95 ASCII glyphs (4479 bitmap bytes); the 16-pixel subset contains
  only `</>` (155 bitmap bytes), totaling 4634 read-only bitmap bytes.
  `display/generate-pixel-font.py` uses an external read-only source font
  pinned by SHA256
  `3a3c502eeff669a231549e80df9f7c49de109bafe303170409e905d0b31a38fe`.
- `display/lvgl_assets.c` contains four rasterized Noto Color Emoji glyphs,
  copyright 2021 Google Inc., licensed under SIL OFL-1.1 in
  `display/assets/ui/noto_emoji/LICENSE.txt`. Upstream revision and source
  hashes are preserved in `display/assets/ui/noto_emoji/SOURCES.json`.
  These historical emoji resources remain in the source tree but are no longer
  linked into the firmware; the pixel face does not use raster emoji assets.

The LVGL 9.5.0 implementation and built-in fonts are consumed from the
repository's pinned `bk_avdk_smp/ap/components/lvgl` component. The terminal
decorations use the separate BK7259 Terminal subsets described above, and
the built-in Unscii 16 font is not enabled. LVGL's license is
recorded in that component's `LICENCE.txt`; source-specific notices remain
applicable. The BK7259 view does not copy the ESP-IDF display driver.
