## 发布阻塞项

以下项目需要代码或契约修改，不能只靠补充测试解决：

1. **凭据日志：** 固定的 SDK HTTPS 调试补丁会在 `NOTICE` 级打印完整请求和响应 body。
   响应可能包含设备、配对或 RTC token。量产前必须删除或脱敏。
2. **证书有效期：** 适配层启用了证书链和主机名校验，但当前 MbedTLS 配置没有启用
   `MBEDTLS_HAVE_TIME_DATE`。必须恢复证书过期和未生效检查并补充测试。
3. **凭据存储：** Wi-Fi 和设备凭据保存在未静态加密的 EasyFlash 中，量产存储保护仍需决策。
4. **RTSA 分发：** 仓库包含专有 RTSA 输入，但没有独立再分发授权记录。发布前必须取得
   书面授权，或从公开制品中移除。
5. **OTA 容量：** 当前 OTA 包占分区超过 98%。增加资源前需加入大小门禁或调整分区。

## 目标板检查

量产前需要：

- 冷启动组合镜像 `all-app.bin`，确认两个核正常运行。
- 反复执行 SDK 启动、停止和会话拆除。
- 验证 Wi-Fi 配网、取消、原网络恢复和掉电处理。
- 验证三路输入采集、AEC、音量和 RTC 双向音频。
- 验证摄像头识别、H.264、帧率、码率调整、IDR 和重复视频会话。
- 验证 LCD、触摸、恢复出厂及存储故障页面。
- 在音频、视频、界面、HTTP 和 RTC 并发时测量栈、堆、PSRAM 和时序余量。
- 验证实际服务的证书链、主机名、有效期和超时。
- 执行长时间运行和看门狗恢复测试。

主机测试和固件编译不能证明目标硬件行为。
